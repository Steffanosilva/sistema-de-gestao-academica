# Sistema de Gestão Acadêmica em C

Este repositório contém o desenvolvimento de um **Sistema de Gestão de Estudantes**, focado na manipulação eficiente de memória através de estruturas heterogêneas, ponteiros e algoritmos recursivos na linguagem C.

O projeto foi desenvolvido como parte de um trabalho acadêmico e portfólio pessoal, com o objetivo de aplicar conceitos de baixo nível para resolver problemas reais de gerenciamento de dados.

## 🚀 Funcionalidades

* **Cadastro de Estudantes:** Armazenamento dinâmico de nome, matrícula e notas utilizando `structs`.
* **Manipulação de Dados:** Inserção, busca e remoção de registros sem limites rígidos de tamanho (alocação dinâmica).
* **Algoritmos Recursivos:** Implementação de funções recursivas para a listagem e busca de alunos na memória.
* **Gerenciamento de Memória:** Uso de listas ligadas para otimização do espaço na memória RAM e liberação total de recursos ao encerrar o programa.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C (Padrão C99)
* **Compilador:** GCC
* **Ferramenta de Controle de Versão:** Git / GitHub
